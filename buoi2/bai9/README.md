 Chuẩn Module Lựa Chọn

Dự án sử dụng chuẩn ESM (ECMAScript Modules).

 Lý Do Lựa Chọn

1\. ESM là chuẩn chính thức của JavaScript hiện đại và được Node.js hỗ trợ nguyên bản `importexport`).

2\. Tối ưu hóa cú pháp rõ ràng, hỗ trợ static analysis và tree-shaking tốt hơn so với CommonJS.

3\. Đồng bộ chuẩn viết mã cho cả ứng dụng Node.js hiện đại lẫn frontend.
